# 安心助手 - 校园应急双模式指引工具

## 📋 项目介绍

**安心助手**是一款专为乡村教师设计的校园应急双模式指引工具，提供心理危机谈心和突发事故急救两种核心功能，帮助教师在紧急情况下做出正确的应对措施。

### 🎯 核心价值
- **快速响应**：提供标准化的应急处理流程
- **专业指引**：基于专业知识的步骤化指导
- **数据管理**：完整的学生档案和记录管理
- **离线可用**：无需网络连接，随时随地使用

## 🚀 主要功能

### 1. 心理危机谈心指引
- **标准化流程**：5步谈心流程，包括情绪稳定、问题澄清、探索例外与资源、激发希望与力量、制定行动方案
- **风险评估**：谈心结束后进行风险评估，确定学生风险等级
- **自动记录**：每一步的选择和学生反馈都会被自动记录
- **记录带入**：谈心完成后，所有记录会自动带入到最终的记录填写页面

### 2. 突发事故急救指引
- **场景分类**：涵盖常见的校园突发事故，如擦伤、骨折、烧伤、中暑等
- **步骤指导**：详细的急救步骤和注意事项
- **紧急联系**：支持自定义紧急联系电话
- **快速访问**：一键进入急救指引页面

### 3. 学生档案管理
- **完整档案**：包含学生基本信息、联系方式、家庭情况等
- **批量导入**：支持通过Excel模板批量导入学生档案
- **模板下载**：提供标准的学生档案Excel模板
- **搜索功能**：快速搜索学生姓名或班级

### 4. 自定义场景管理
- **场景创建**：支持教师自定义谈心和急救场景
- **场景编辑**：修改和删除自定义场景
- **场景分类**：按类型和优先级组织场景

## 📱 使用说明

### 基本操作
1. **启动应用**：在浏览器中打开 `index.html` 文件
2. **选择功能**：在首页选择谈心指引或急救指引
3. **按照指引操作**：根据屏幕提示完成每一步操作
4. **保存记录**：完成后填写相关记录并保存

### 学生档案管理
1. **添加学生**：点击右下角的「+」按钮添加新学生
2. **批量导入**：点击「导入学生档案」按钮，选择Excel文件
3. **下载模板**：点击「下载学生模板」按钮获取标准模板
4. **编辑档案**：点击学生卡片进入详情页面进行编辑

### 自定义场景
1. **进入设置**：点击首页右上角的设置图标
2. **创建场景**：在自定义场景部分点击「添加场景」
3. **填写信息**：输入场景名称、类型和内容
4. **保存场景**：点击保存按钮完成创建
